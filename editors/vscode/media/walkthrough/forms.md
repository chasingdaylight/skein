# Forms for items

**New Item...** (the Items view's title bar, the **Skein** menu of a Markdown editor, the command palette) opens a form of the item's type, ID, category, status, attributes, links and text, and where it goes. **Edit Item...** (the editor's context menu on an item, or the item's context menu in the Items view) opens the same form for an item that is there. Saving writes the marker or the item's front matter, and opens the item.
