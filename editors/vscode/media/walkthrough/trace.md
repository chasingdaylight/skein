# Trace, coverage, plan and graph

- **Trace**, above each item (a code lens) or in the editor's context menu: the item with everything above and below it, its citations in code and tests, and its results.
- **Show Coverage**, also the status bar's percentage: what is not yet linked or cited as the project expects.
- **Show Plan**: the work items in a Gantt chart and on a board, whose drags are written into the items.
- **Show Graph**: the network of items and links, with search and filters.

The status bar's Skein item opens a list of all of Skein's commands.
