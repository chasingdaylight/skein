# Cost estimate and schedule

The software cost estimates (%[SWE-015], %[SWE-151], %[SWE-174]) and schedule (%[SWE-016], %[SWE-018]).

## Cost estimate

One model for a class C project (%[SWE-015]): analogy with the facility's last rover, 1,200 lines of C in 6 months of 2 people. This one is about 800 lines: 4 person-months, redone at each review.

## Schedule

SRR in January 2027, the design and test readiness review in March, the first field test in April; the rover's hardware is delivered in February (%[SWE-046]: no suppliers of software).
