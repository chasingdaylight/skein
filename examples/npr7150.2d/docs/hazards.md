# Software and hazards

The system hazards that software causes, controls or mitigates, and the software requirements that address them (%[SWE-052], %[SWE-192]), after handbook topic 5.24. Each is an item of the type `hazard`, `HAZ-001` and on, often kept by the system's safety analysis in another repository of the network.

None: the rover's hazard analysis, HA-R-01, finds no hazard that the drive software causes, controls or mitigates (the [safety-criticality determination](safety-criticality.md)). This page is kept so that one added later is traced at once.
