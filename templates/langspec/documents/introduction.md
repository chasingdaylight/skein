# Introduction

This specification describes a programming language as rules, each an item that can be cited, tested and traced. A rule says what is written (syntax), what is allowed (legality), what a program means before it runs (static semantics) or as it runs (dynamic semantics). The examples under a rule show it and are tested: an example that is to be rejected says so.

%term[intro.program] A program is the text a compiler of the language reads and the meaning the rules give it.

%rule[intro.encoding syntax see=intro.program] The source text of a program shall be UTF-8.
