# Software assurance and software safety tasks

%sass[SASS-01] The responsible project manager shall perform the software assurance and software safety activities defined in Table 1 per the requirements marked applicable in the software engineering requirements mapping matrix for the software component.

The tasks of Table 1 of the standard, for each requirement of NPR 7150.2D: each group an item (`SA-033`) that assures the requirement, each task a part of it (`SA-033.1`).

## SWE-033 (3.1.2)

%satask[SA-033 assures=SWE-033 classes=A,B,C,D,E,F applies=always] The software assurance and software safety tasks of SWE-033.

- %satask[.1] Confirm that the options for software acquisition versus development have been evaluated.
- %satask[.2] Confirm the flow down of applicable software engineering, software assurance, and software safety requirements on all acquisition activities. (NPR 7150.2 and NASA-STD-8739.8).
- %satask[.3] Assess any risks with acquisition versus development decision(s).
